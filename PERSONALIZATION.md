# Personalization and setup

Run `npm install` and `npm run dev`, then open the local address printed by Vite. `npm run build` builds the site; `npm run lint`, `npm run test`, and `npm run test:e2e` run the checks (browser tests use installed Google Chrome). See `SETUP.md` for the architecture and full setup.

Edit `src/data/personal.ts` to add her name, occasion, message, interests, reminders, initial memories, and gallery photos. Empty optional fields have empty states; missing letters are not replaced with generic personal messages. `currentLocation`, `studyLocation`, and `fieldOfStudy` hold the geographic/study context. `surpriseMessage` optionally overrides the letter for the 3D garden gift. The new Baguio–Quezon City love story uses `story`, `senderLocation`, and `connectionLetter`. Its romantic copy is written from the love you expressed, without invented memories; edit it to sound more like you. Supplied `message` or `surpriseMessage` takes precedence over the drafted ending. Place photos in `public/photos` and reference local paths such as `/photos/portrait.webp`, with descriptive alt text. Anyone with access to a publicly hosted static site can see content included in it.

Memories created in the interface are stored in this browser's IndexedDB on this device; they do not sync and may be lost if browser data is cleared. This is not private cloud storage. Existing browser-local memories are copied into IndexedDB on first use; the original legacy data is not deleted. Export a JSON backup to keep or transfer them; import validates the file. Local uploaded photos are included, subject to browser storage limits. Project-configured memories are edited in `src/data/personal.ts`. Export includes the displayed configured and local memories, embedding referenced local photos so the JSON is portable. Imports keep existing matching IDs rather than overwriting them. At most 100 memories per backup, 12 MB per JSON file, and 2 MiB per JPEG/PNG/WebP photo are accepted; browser quota may be lower. Export fails clearly rather than silently omitting an unavailable configured photo. Keep backups safe: they contain personal content and photos. Shared storage and access controls are not included.
