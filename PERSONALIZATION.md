# Personalization and setup

Run `npm install` and `npm run dev`, then open the local address printed by Vite. `npm run build` builds the site; `npm run lint`, `npm run test`, and `npm run test:e2e` run the checks (browser tests use installed Google Chrome). See `SETUP.md` for the architecture and full setup.

Edit `src/data/personal.ts` to add her name, occasion, message, interests, reminders, initial memories, and gallery photos. Empty optional fields have empty states, and the default letter is labeled as an example. Place photos in `public/photos` and reference local paths such as `/photos/portrait.webp`, with descriptive alt text. Anyone with access to a publicly hosted static site can see content included in it.

Memories created in the interface stay in the current browser and device; they do not sync and may be lost if browser data is cleared. Export a JSON backup to keep or transfer them; import validates the file. Local uploaded photos are included, subject to browser storage limits. Project-configured memories are edited in `src/data/personal.ts`. Export includes the displayed configured and local memories, embedding referenced local photos so the JSON is portable. Imports keep existing matching IDs rather than overwriting them. At most 100 memories per backup, 12 MB per JSON file, and 2 MiB per JPEG/PNG/WebP photo are accepted; browser quota may be lower. Export fails clearly rather than silently omitting an unavailable configured photo. Keep backups safe: they contain personal content and photos. Shared storage and access controls are not included.
